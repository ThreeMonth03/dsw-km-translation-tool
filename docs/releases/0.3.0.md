# 0.3.0

The tool now focuses on official Registry Knowledge Models, Weblate-backed
translation contributions, and native DSW PO locale releases.

- Remove the retired Taiwan KM draft/legal tooling, custom source-KM release
  tools, GitHub-only source synchronization, and their configuration profiles.
- Use configuration schema 3. Remove `knowledge_model.bundle_path`; artifact
  paths are derived from KM coordinates. Unknown fields are rejected.
- Bootstrap and local builds share one PO build pipeline.
- Include artifact path safety tests in the normal CI suite and reject
  symlinked scaffold targets before writing any managed files.

Update the configuration and pin this release's full tooling commit before
refreshing the managed scaffold. Translation Markdown and PO content do not
need to change. Existing release tags and assets remain historical records.
