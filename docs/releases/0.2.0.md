# 0.2.0

Translations are published as native Knowledge Model PO locales for DSW 4.33
or newer. Translation repositories use configuration schema 2.

- Markdown-only pull requests in Weblate-backed translation repositories produce
  validated PO review artifacts.
- Canonical shared translations are expanded automatically during review and
  post-merge Weblate import; conflicting edits still require review.
- Locale releases use `km-<KM version>-<language>-r<revision>` tags and include
  checksums plus source, translation, and tooling provenance.
- Every source mode uses the same locale release workflow. Scaffold sync removes
  managed files belonging to other source modes.
- Gettext metadata headers are excluded from translation counts.

The translated-KM builder and supplemental translations have been removed.
Pin `tooling.ref` to the full commit of this release, update the repository to
schema 2, and refresh its managed scaffold before using these workflows.
