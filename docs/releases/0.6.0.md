# 0.6.0

- Publish exactly three locale assets: the versioned PO, `manifest.json`, and
  `SHA256SUMS`. Release notes remain in the release page body; the configuration
  remains available at the translation commit recorded in the manifest.
- Prepare uploadable files in `assets/`, separate from release notes. Release
  workflows upload an explicit file list instead of the whole output directory.
- Keep complete browser coverage details in `coverage.json`; `result.json`
  contains only coverage status, counts, and the report path.
- Reuse parsed PO blocks for native model validation and translation-tree
  construction. Share download validation between sync and KM update checks.

Use the versioned PO filename for downloads. No unversioned alias is published.
Existing releases and test fixtures remain unchanged. Source readiness checks,
native DSW browser verification, and the pinned `dsw-models` dependency remain
in place.
