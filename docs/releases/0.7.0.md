# 0.7.0

The official Weblate/POT catalog now controls translation synchronization
independently of the available Knowledge Model version.

- Sync current source text, translations and fuzzy flags without waiting for a
  matching KM. Removed upstream content is not restored locally.
- Export every referenced catalog entity as editable Markdown. The KM supplies
  known hierarchy; catalog-only entities appear at the tree root.
- Report KM source differences and cross-version POT coverage without blocking
  a valid locale. Keep syntax, language, reproducibility and browser import checks.
- Recognize complete upstream mirror refreshes in PR checks without treating
  upstream removals or formatting as new human translation errors.
- Update the context KM from the latest published Registry release independently
  of the catalog version.
- Publish with `locale-<language>-r<revision>` tags. Manifest schema 2 separates
  Weblate snapshot provenance from `context_knowledge_model`; asset filenames no
  longer imply a required KM version.

Update downstream tooling pins and regenerate managed docs/workflows before
publishing with the new tag format. Existing release tags and assets are unchanged.
