# v0.7.1

Source sync and KM updates now stop before replacing files when Git contains
translation edits that have not reached Weblate. This protects individual and
canonical shared translations, including deliberate empty translations, if an
import fails or another writer runs first.

Complete or retry the reviewed GitHub Translation Import before syncing again.
Once Weblate contains the edits, normal mirroring resumes. Official source
changes, removals and fuzzy flags remain authoritative; no KM version gate or
additional configuration is introduced.
