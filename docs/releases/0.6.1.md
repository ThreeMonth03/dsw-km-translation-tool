# 0.6.1

- Validate PO references against the exact KM field. A missing or null field
  cannot pass validation by borrowing text from another field.
- Remove unused tree-snapshot settings and outline/shared-block properties.
- Clarify that a sync without a commit can mean `waiting-for-km`, not alignment
  with Weblate. Update maintenance and release instructions for this state.

Existing valid PO files and tree display labels are unchanged. The pinned
`dsw-models` dependency and the input normalization it requires remain unchanged.
