# 0.4.1

- Daily native locale verification now distinguishes missing upstream source
  strings from incomplete locale coverage. Reports retain the public upstream
  POT and its immutable commit and checksums.
- Add `dsw-km-report-source-catalog` for read-only, same-KM-version source audits.
  Invalid or wrong-version catalogs fail; source differences require upstream
  review and do not trigger uploads or translation replacement.
- Document the official upstream review and POT-to-PO merge process, including
  safeguards for existing translations in all languages.

The Weblate-first translation workflow and `dsw-models` dependency are unchanged.
Translation repositories must update their tooling commit and regenerate the
managed scaffold to use the new audit. Existing PO releases remain valid.
