# 0.5.0

- Use the official native PO reference format, `entity/UUID/field`. Empty,
  malformed, unmapped, or unsupported catalogs fail instead of producing an
  empty translation tree or a successful zero-message status report.
- Validate downloaded PO syntax, language, and source fields against the
  configured KM before replacing an existing snapshot. Tree refresh and
  repository builds also validate their inputs before modifying translations.
- Use upstream MinIO images from Quay for disposable native DSW browser tests.

Before upgrading a translation repository, obtain a current Weblate catalog and
its matching official KM bundle. Colon-separated reference catalogs are no
longer accepted. Weblate and the Registry can publish independently; an
unpublished KM must not be replaced by relabeling an older bundle or removing
unmatched source messages.

The Weblate-first workflow and the pinned `dsw-models` dependency are unchanged.
