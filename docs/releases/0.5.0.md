# 0.5.0

- Read official native PO references without rewriting existing snapshots. Empty,
  malformed, unmapped, or unsupported catalogs fail instead of producing an
  empty translation tree or a successful zero-message status report.
- Validate downloaded PO syntax, language, and source fields against the
  configured KM before replacing an existing snapshot. Tree refresh and
  repository builds also validate their inputs before modifying translations.
- Use upstream MinIO images from Quay for disposable native DSW browser tests.
- Report `waiting-for-km` when a valid upstream POT and PO target a different
  KM. Preserve the last verified snapshot, tree, and locale; continue checking
  repository integrity. KM updates validate a candidate pair before applying it.

Weblate and the Registry publish independently. An unpublished KM must not be
replaced by relabeling an older bundle or removing unmatched source messages.
Syntax errors, unrecognized references, and same-version source mismatches still
fail CI. Waiting is not a successful sync or a complete coverage result.

The Weblate-first workflow and the pinned `dsw-models` dependency are unchanged.
